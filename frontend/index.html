Decision-support output only. Not food-safety, SNI, histamine, or export certification.

Condition

AI estimate of lot condition from tabular features.

  • NORMAL: visual proxy 0-5, generally normal.
  • CHECK: visual proxy 6-10, needs attention.
  • POOR: visual proxy 11-16, higher concern.

Risk Score

Predicted quality downgrade risk from the AI model. Higher means more urgent.

  • 0-30: lower risk.
  • 31-60: watch / moderate risk.
  • 61-100: high risk, prioritize action.

Recommendation

Operational action suggested by the model.

  • HOLD_CHILLED: keep chilled, no urgent action.
  • RE_ICE_AND_ROUTE: add ice / improve cold-chain, then route.
  • PROCESS_IMMEDIATELY: process quickly.
  • MANUAL_INSPECTION: human inspection recommended.
  • DOMESTIC_CHILLED: route as chilled domestic lot.
  • PROCESS_EXPORT_CANDIDATE: candidate for processing/export scenario.
  • LOCAL_FRESH_ONLY: local fresh route only.

Probability

Model confidence for the top condition or action. It is not a food-safety probability.

Key Signals

Input factors that help explain the prediction.

  • Remaining quality window: estimated hours before quality window runs out.
  • Max temperature: highest recorded temperature.
  • Time above 10 C: duration of stronger thermal exposure.
  • Visual proxy score: manual/synthetic visual score from 0 normal to 16 poor.

Visual Anomaly

Photo-based comparison against normal lemuru reference images.

  • NORMAL: similar to reference photos.
  • CHECK: somewhat different; inspect if needed.
  • ANOMALOUS: noticeably different from reference photos.

Lot ID

Unique name/code for the new fish lot. Example: NEW-LEMURU-001.

Lot Mass kg

Total mass of the lot in kilograms. This helps represent shipment scale.

Handling Scenario

Current handling condition, such as controlled ice, delayed chilling, melted ice, or loading excursion.

Target Market Node

Destination scenario code used by the MVP dataset. It represents where the lot is planned to go.

Mean Temp C

Average product temperature from logger/sensor history. Higher average temperature can increase quality risk.

Max Temp C

Highest recorded product temperature. This captures possible temperature excursions.

Hours > 4 C

Total time above 4 C. This indicates mild cold-chain exposure for chilled fish.

Hours > 10 C

Total time above 10 C. This is a stronger warning signal than time above 4 C.

Hours > 15 C

Total time above 15 C. Larger values usually indicate severe cold-chain abuse.

Remaining Quality Window h

Estimated hours left before quality window becomes too short. Smaller values mean higher urgency.

Visual Proxy Score 0-16

Structured visual/sensory score. Use 5 as default if unknown.

  • 0-5: normal reference.
  • 6-10: check / moderate concern.
  • 11-16: poor / high concern.

Photo Optional

Uploaded photo is used for visual anomaly screening only. It does not replace visual proxy score in the XGBoost model.

Save This Manual Lot

If checked, the manual row is appended to the local CSV dataset used by Dataset Mode.
